# rednotes 📕

> 中年程序员的职场与生活 

**从小红书刷过来的粉丝朋友**——欢迎你们！

## 🤝 欢迎参与

这个仓库是开放的，非常欢迎大家参与进来：

- **提交 PR**：不管是内容补充、错字修正，还是你自己的二创作品（放进 [`网友二创/`](./网友二创/) 文件夹），统统欢迎；
- **提交 Issue**：想聊的话题、想看的选题、或者单纯想打个招呼，都可以开一个 Issue。

## 📁 目录结构

```
.
├── 网友二创/   # 小红书网友们的二创作品，每件作品都在文件夹 README 里标注了作者
└── 网友问答/   # 精选网友提问（暂空），有代表性的问题会整理收录在这里
```
